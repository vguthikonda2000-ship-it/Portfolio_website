# Portfolio Site

- `index.html`, `styles.css`, and `script.js` control the design and behavior.
- `content/default-content.js` stores all content: text, links, and images (embedded as base64).

## Updating content

Open `editor/index.html` locally, make your edits, click **Export to File**, and replace `content/default-content.js` with the downloaded file. Then commit and push.
